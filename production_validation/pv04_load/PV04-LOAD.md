# PV-04 — Sustained Load

Purpose:
Measure a baseline rather than invent a capacity target.

Workloads:
- 100 observations
- 1,000 observations
- 5,000 observations

For each workload:
- insert observations
- transition every observation
- verify observation count
- verify event count
- verify no state remains untransitioned

The measured operations/second values are environmental baselines only. They are not product capacity limits.
